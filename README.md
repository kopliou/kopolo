# KOPOLO — Осколки витражного мира

2D-шутер с видом сверху в бесконечном открытом мире: добывай ресурсы, выращивай урожай, сражайся с тварями пяти земель и одолей четырёх Хранителей.

Вся графика процедурная и собрана из «витражных» граней со свинцовыми швами — в репозитории нет ни одной картинки. Звуки синтезируются на лету. Зависимостей нет: только HTML, CSS и JavaScript-модули.

## Запуск

```bash
npm run dev     # http://localhost:5173 (порт меняется переменной PORT)
npm run build   # dist/kopolo.html — вся игра одним файлом
npm test        # тесты симуляции, нужен Node.js 20+
```

`dist/kopolo.html` открывается двойным щелчком — без сервера и без интернета. Сам `index.html` с диска не запустится: браузеры не загружают JS-модули со страниц `file://`. Ему нужен сервер: `npm run dev`, любой другой статический сервер или GitHub Pages.

## Управление

| Клавиши | Действие |
| --- | --- |
| `W` `A` `S` `D` или стрелки | движение |
| мышь, ЛКМ | прицел и огонь |
| `1`–`6`, колесо мыши | выбор оружия |
| `Пробел`, `Shift` или ПКМ | рывок — неуязвимость к снарядам |
| `F` / `Q` | посадить семя перед собой / выбрать вид семян |
| `E` | собрать созревший урожай, пробудить Хранителя у алтаря |
| `Z` `X` `C` | съесть светоягоду, огнеперец, морозник |
| `Tab` или `B` | мастерская: улучшения и оружие |
| `M` | карта мира |
| `T` (удерживать) | возврат к Маяку |
| `Esc` или `P`, `N` | пауза, звук |

## Что есть в игре

- **Открытый мир.** Бесконечная карта создаётся по зерну мира: Луга, Чаща, Пески, Стужа и Пепелище, озёра и лава, день и ночь. Чем дальше от Маяка, тем сильнее твари.
- **Фарминг.** Деревья, камни и кристаллы разбиваются выстрелами и со временем вырастают снова; из тварей выпадает эссенция, семена и ресурсы. Семена можно посадить: светоягода лечит, огнеперец усиливает урон, морозник защищает. Каждая культура быстрее зреет в «своих» землях.
- **Твари.** Одиннадцать видов со своим поведением: прыгуны, стрелки, таранщики, подрывники, турели. Ночью их больше, а среди них чаще встречаются элитные — с богатой добычей.
- **Хранители.** Четыре босса со сменой фаз: Корнеглав, Зыбун, Стужень и Игнис. Их алтари отмечены на карте; ядро каждого Хранителя открывает новое оружие, а повторно пробуждённый Хранитель становится сильнее.
- **Развитие.** Шесть видов оружия и семь улучшений в мастерской. Маяк в центре мира лечит и не пускает тварей. Прогресс сохраняется в браузере.

## Устройство кода

- `src/game.js`, `src/world.js`, `src/bosses.js`, `src/config.js` — симуляция без обращения к DOM (её же прогоняют тесты в `tests/`).
- `src/render.js`, `src/sprites.js`, `src/hud.js` — отрисовка на canvas: мозаика ландшафта, спрайты, частицы, ночное освещение, интерфейс.
- `src/main.js`, `src/ui.js`, `src/input.js`, `src/audio.js`, `src/save.js` — игровой цикл, меню, ввод, звук и сохранения.
- `scripts/serve.mjs`, `scripts/build-single.mjs` — сервер для разработки и сборка игры в один файл.
